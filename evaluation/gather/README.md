# Gather 公开开发校准

这里保存实际 V1 的基线检查、旧数据样本及对应证据。它们用于公开开发校准，不是独立未见测试集，也不替代产品计划中的正式批准或 Evidence。

## 复跑

在已安装依赖的 EasyMint 仓库中使用 Node 执行：

```sh
node evaluation/gather/probe-v1.mjs "/path/to/Gather" "/path/to/new-evidence-directory"
```

要求 Gather 为干净的 V1 Git 工作树，证据目录尚不存在。探针将实际领域层和 Repository 打包到临时目录运行，只使用内存存储，不运行模型，不访问浏览器 localStorage；执行结束清理临时包。

报告冻结 Git 提交、全部跟踪文件的 SHA-256（含锁文件）、探针自身摘要、Node 版本，以及 F1 序列化和落盘文件两个摘要。文件尾部新增换行，所以两种摘要不同。F1 使用真实 V1 写入路径生成，后续 V2 只能读取该样本作为迁移输入。

当前结果：8 项业务/数据/持久化检查通过；V2 跨场成功条件在真实 V1 上预期失败。页面部分仍需实际观察；报告 remaining 字段逐条保留未验证内容。探针失败时退出非零，不输出成功报告；证据目录已存在时拒绝覆盖。

适配器只用于当前 Gather V1 已核验 API，不应直接作为跨项目通用评分器。后续 V2 可以采用不同内部结构，验收依据始终是公开业务语义。
